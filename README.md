# אתר בקליק – בונים אתר לעסק בכמה דקות

אתר מקצועי לעסק, עם מסך ניהול מלא – תורים, לקוחות, הזמנות, תקבולים ועוד – מותאם לתחום שלכם.

## 💼 שרת פרטי משלכם – הקמה בלחיצה

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/MM67938/site-builder)

**מה מקבלים:**
- שרת שכולו שלכם, בחשבון שלכם. האתר תמיד דולק ולא „נרדם”.
- האתר מופיע בכתובת הראשית של השרת, ואפשר לחבר אליו דומיין משלכם (למשל `my-business.co.il`).
- כל הנתונים שלכם – לקוחות, תורים, פניות – נשמרים בשרת שלכם בלבד.

**עלות:** משלמים ישירות ל-Render, בכרטיס האשראי שלכם – בערך 7.25$ לחודש (שרת Starter ‏7$ + דיסק לנתונים). אין תשלום נוסף לאף אחד.

**איך מקימים:**
1. לוחצים על הכפתור הכחול **Deploy to Render** למעלה.
2. נרשמים ל-Render (אפשר עם Google או GitHub) ומוסיפים כרטיס אשראי (**Billing**).
3. לוחצים **Deploy Blueprint** (או **Apply**) ומחכים כמה דקות עד שמופיע **Live**.
4. נכנסים לכתובת שמופיעה בראש הדף (למשל `https://my-business-site.onrender.com`), בונים את האתר ולוחצים **🚀 פרסום**.
5. מעכשיו:
   - **האתר** בכתובת הראשית.
   - **מסך הניהול** ב-`/admin/site`.
   - **בונה האתרים לעריכה** ב-`/builder`.

**דומיין משלכם (לא חובה):** ב-Render ← השירות ← **Settings** ← **Custom Domains** ← **Add Custom Domain**, ומעדכנים אצל ספק הדומיין לפי ההוראות שמופיעות שם.

**עדכון לגרסה חדשה:** ב-Render ← השירות ← **Manual Deploy** ← **Deploy latest commit**.
